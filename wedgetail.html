GLG Camera Rep Counter

One camera, two independent tracking zones — each one automatically finds and follows its athlete, so you don't need to nail an exact camera position. Pose estimation counts reps off a hip–knee angle cycle (squat / deadlift movement pattern), deliberately generously — the count is meant to be crude and fast, not a form judge. All quality control lives with the coach, made live via NO REP. Tracking itself runs entirely in this browser tab; the raw camera feed from GO to Reset is uploaded afterwards so coaches can review it, with reps close to the cutoff flagged for a second look.

Camera setup for a real test: tripod or propped device, framing both lanes side by side, each athlete visible head-to-ankle from a side-on angle. Good even lighting, no one crossing between the two lanes mid-set.
  • The clock never pauses — only the counter's start does. The camera can be live and framing/calibrating the moment it's mounted, but nothing counts until the judge taps BOTH READY — GO. That's the moment both athletes are acknowledged set — the same beat a human judge already takes before counting the first rep, just made explicit. Use Reset for Next Station once a station ends to clear counts, drop calibration, and disarm ready for the next remount.
  • Two different "bottom" checks, because they're two different physical facts. Goblet Squat's validity is a body position — hip crease below the knee — so joint-angle mode is the right tool. Trap Bar Deadlift and DB Snatch are actually judged on an equipment fact — the weight returning to the floor between reps — which a body-only pose model can't see directly. "Weight-to-floor" mode gets there anyway: it calibrates once to the athlete's wrist height while the bar is genuinely resting on the floor, then treats "wrist back at that height" as the floor check. Re-calibrate whenever the bar, plates, or athlete changes.
  • This build tracks a hip–knee–ankle extension cycle for lockout in both modes. Push Press needs a different state machine again — its bottom is a rack position at the shoulder, not a floor check — tracking shoulder–elbow–wrist instead; not wired up in this prototype.
  • If a lane shows tracking: low, the model can't see that athlete's joints clearly — counting pauses automatically rather than guessing.
  • NO REP removes the last counted rep for that lane — same action as the "−" button already in the Live Counter screen. +1 adds one back if the camera missed a genuine rep.
  • Live scoring: enter the Fixture ID and category above and tap Connect Live Scoring (you must be logged in as the judge assigned to that category). Each auto-count, +1, or NO REP then writes straight to the same /api/judge/fixture/:id/category/:cat/result endpoint the Live Counter screen uses — so the scoreboard, Watch Live, and Cast Display all update as this camera counts, not after the fact. Leave it disconnected to run this as a local-only rep counter.
  • Recording: from BOTH READY — GO until Reset for Next Station, the raw camera feed (both lanes, exactly what's on screen) is recorded and, on reset, uploaded for coaches to review afterwards. Reps whose bottom position was close to the live cutoff — not necessarily bad, just close — get flagged with a timestamp so a coach can jump straight to them. This never changes what counted live; it's coaching material, not a scoring appeal. If the upload fails (e.g. bad connection), the reps already counted are unaffected — only the clip is lost.
